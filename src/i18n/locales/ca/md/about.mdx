# Sobre el projecte

<br />

Mems Catalans és un lloc web senzill i ràpid per crear i compartir mems. Hi ha una [llista de mems](/gallery/) disponible per defecte, però també pots importar la teva pròpia imatge.

<br />

Pots descarregar el mem personalitzat al teu dispositiu o copiar-lo al porta-retalls. No deso els teus mems en cap base de dades, així que recorda exportar la teva feina.
