# Sobre el projecte

<br />

Meme Studio és un lloc web senzill i ràpid per crear i compartir memes. Hi ha una [llista de memes](/gallery/) disponible per defecte, però també pots importar la teva pròpia imatge.

<br />

Pots descarregar el meme personalitzat al teu dispositiu o compartir-lo directament al teu compte de Twitter. No deso els teus memes en cap base de dades, així que recorda exportar la teva feina.

<br />
